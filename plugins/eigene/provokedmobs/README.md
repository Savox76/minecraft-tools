# ProvokedMobs 1.2.0

Creeper explodieren nicht mehr, umschaltbar per Chat.

Schützt Bauwerke und Spieler vor Creeper-Explosionen. Admins schalten den Schutz im Chat um, alle Spieler sehen die Meldung.

> Status: Dokumentation verfügbar. Quellcode und `.jar`-Download folgen.

## Funktionen

- Creeper explodieren nicht (kein Block- und kein Spielerschaden)
- Schutz per Chatbefehl an- und ausschaltbar, mit Meldung an alle

## Befehle

| Befehl | Was er macht | Wer |
|---|---|---|
| `/mobschutz an \| aus \| status` | Mob-Schutz schalten oder anzeigen | Admin |
| `/mobschutz creeper an \| aus` | Nur den Creeper-Schutz schalten | Admin |
